## Exercise 1 - done with the lecturer

* Create a function named `getDatasInfo(elements)` and pass `links` variable to it as an argument (remember that it is a pseudo-array)

## Exercise 2

Write all the variables in the console. Check which of them are pseudo-arrays.

Iterate through pseudo-arrays (e.g. using the **for** loop). Write tag name and class of each element.


## Exercise 3

## Exercise 4
