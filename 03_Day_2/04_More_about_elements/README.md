## Exercise 1 - done with the lecturer

Modify the list in the `.exercise` section as follows:

1. Set the background color of every second list element to grey (`#9e9e9e`),
2. Set ```big``` **class** for the fifth element of the list,
3. Set underlining for every third element of the list.


## Exercise 2

There are three images with icons of the most popular web browsers on the page. Unfortunately, both images and links leading to their pages contain errors.
Write JavaScript code which will make the following changes:

1. Fix the elements so that the appropriate logo was attached to each browser (the image is set using ```background-image```).
2. Fix links so that each one has the correct description and ```href``` attribute.
3. Fix the width of the element with the ```chrome``` class (should be 100px).


## Exercise 3

There is a list on the page, where you have to enter your name, your favorite color and meal.
1. Find the appropriate items (spans) and save them to variables.
2. Use ```innerText``` to fill them with the correct information.


## Exercise 4

The page has a simple menu. Both HTML and CSS code is already prepared for it. Unfortunately, someone forgot to add the appropriate classes to the elements.
1. Find the `ul` element in the `.exercise` section and add the class `menu` to it.
2. Find all `li` elements in the `.exercise` section and add the ```menuElement```  class to them (use a loop for this). Be careful not to delete the ```selected``` class.
3. Note that one of the elements has a red background color. This is because it has the ```error``` **class**. Remove it from this element (it is best if you remove this **class** from all the elements that have it).


## Exercise 5

To each list element in the `.exercise` section, add the ```data-id``` attribute with values of successive integers (starting with 1).
