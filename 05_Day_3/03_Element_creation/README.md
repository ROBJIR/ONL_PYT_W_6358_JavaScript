## Exercise 1 - done with the lecturer

There is a table with orders on the page. There is a button next to each order, which is used to delete this order.
Add an appropriate event to it, which will make the order disappear from the table. Try to do it in such a way that all buttons use the same event (use ```this```).


## Exercise 2

There is a button on the page. You must add an event to it so that when you click on it, it is removed from the page.


## Exercise 3

On the page made for this exercise, there is a list and a button. Add appropriate events to them so that when you click on the button, a new element is added to the list. The element should have information about how many elements are on the list at the time of adding it.


## Exercise 4

There is a table with information about orders (with two already entered orders) on the page.
Below, there is a form for filling in a new order. Write an event that will take information from inputs (```el.value```) and enter a new entry into the table.


## Exercise 5

There is a list of entries and a button on the page. Write an event that all list children are removed from the list when you click on the button. The ```ul#list``` element should remain on the page.


## Exercise 6

There are two lists on the page. Each of the entries is "clickable".

Write a JavaScript code so that when you click on an element of one list, it is moved to the second list.

Remember that an element can be moved multiple times (e.g. from list 1 to list 2 and then back to list 1).
