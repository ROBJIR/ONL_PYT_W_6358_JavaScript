## Exercise 1

There is a section with two ```article``` elements on the page.
In each article there are elements `h5`, `a`, and `div` with the class `content`, which is hidden in the CSS (class `d-none`).

Your task is to:

* set an event on the first link, which will show an element with the class `content` (belonging to this article) when the user clicks on the link.
* set an event on the second link, which will show an element with the class `content` (belonging to this article) when the user hovers over the link with his mouse.
