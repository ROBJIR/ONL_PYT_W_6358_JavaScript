## Exercise 1

There is a pizza order form on the website. In the form there is a box with checkboxes, where the user can choose toppings.

The price of each topping is held in attribute ```data-price```.

Write such events so that after checking the checkbox the correct order amount is displayed and after sending the form inside ```order-info``` element the following information is displayed: **"To pay: [appropriate amount]"**, where [appropriate amount] is the order value (price for extra toppings + $ 10 base for pizzas). Remember that clicking on the button will trigger the default page reloading action. Block this action to see information entered in ```order-info``` element.

Pay attention to the two special buttons:
* Clear - should deselect all options,
* All toppings - should mark all options
