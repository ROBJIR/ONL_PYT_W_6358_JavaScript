## Exercise 3

In the file `js/app.js` create a function that will write "Hello" in the console. Test the place where this function is called.

First call it after the function definition and then before. Write down your observations in a comment.
Then create a second function, which will write another text in the console, e.g. "Hi". Create it as
a function expression (i.e. assign the definition to a variable).

Then try to test the place where it was called similarly as with the first function. Write your observations in a comment.
