## Exercise 1 - done with the lecturer

Test the `setTimeout` and `setInterval`. Run an interval that will display "Generated from setInterval" in the console every `10s`, and also a timer that will print "JavaScript Rules" in the console after `4s`.


## Exercise 2

Write a `countHello()` function, which will take an integer from the range 1-10 as a parameter. Run a `setInterval` in this function. Let it write  on the console: the text "Hello" and a counter adding how many times the `setInterval` has already been started.
If the counter reaches the value given for the function as parameter, `setInterval` should be cleared.
