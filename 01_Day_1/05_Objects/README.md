## Exercise 1 - done with the lecturer

Create an object `country`. Add the following properties to it:

* `capital` - string,
* `population` - number,
* `president` - string,
* `ministers` - array of strings

Display all properties in the console.


## Exercise 2 - done with the lecturer

Create an object `timeMachine`. Add the following properties to it:

* `shape` - string,
* `model` - string,
* `run(date, place)` - a method that enables travel in time. The argument `date` is the date you want to travel to, and `place` is the place you want to travel to. Both arguments are strings.

Print out all properties in the console and call the `run` method.


## Exercise 3

Create an object `book`. Add the following properties to it:

* `title`,
* `author`,
* `numberOfPages`.

Print out these properties in the console.


## Exercise 4

Create an object `person`. Add the following properties and method to it:

* `name`,
* `age`,
* `sayHello()` - displays the string "hello"

Display the properties in the console, call the method.


## Exercise 5

Create an object that will store your favorite recipe. The object should have the properties: `title` (string), `servings` (number) and `ingredients` (string array).

Add the field `ingredients` outside the object's body.

Display all these information in the console.


## Exercise 6

Copy the following code to the file ```js/app.js```:

```js
const spoon = {
  isExist: true
}

const fork = spoon;
fork.isExist  = false;
```

Then check if the spoon exists.
